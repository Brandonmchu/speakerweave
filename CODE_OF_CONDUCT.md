# Code of Conduct

SpeakerWeave follows the [Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

For enforcement questions or to report unacceptable behavior privately, contact the maintainers through the repository's [private GitHub advisory form](https://github.com/Brandonmchu/speakerweave/security/advisories/new). All reports will be reviewed promptly and handled as confidentially as possible.
